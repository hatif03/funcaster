Scope: the implementation in this tree. See [IMPLEMENTATION.md](IMPLEMENTATION.md) for the feature ledger and conditional work. This is engineering evidence, not physical-device or launch acceptance. No merge or deployment was performed.

## Automated checks

- `npm run check`: all 13 generated catalogs agree, recursive bundle validation passes, and **300 unit tests plus 68 party tests pass**.
- `npm run format:check` and `git diff --check`: pass.
- `STRESS_SECONDS=60 npm run test:stress`: four rooms and sixteen simulated controllers sustained WebSocket input for one minute; 28,432 input packets, 13,436 frames, ping p95 **4.39 ms**, event-loop p99 **13.82 ms**.
- `STRESS_POLLING=1 npm run test:stress`: the same four-room/sixteen-controller fixture passed over polling for five seconds; 2,416 input packets, 1,204 frames, ping p95 **14.83 ms**, event-loop p99 **13.99 ms**.
- These load figures are local Node client/server measurements on one laptop. They do not establish mobile-network latency, hardware temperature, sensor accuracy or a one-hour soak.
- Coverage includes delegated-host scope/revocation, kiosk PIN limits, queues, outcomes, room limits, remote grant misuse/expiry/recovery, replay checking, event-store persistence, shared pickup arbitration, drawing votes, controller pacing, bundle validation and SDK lifecycle. Both transports exercise repeated four-seat reconnects.

## Determinism and sequencing spike

`npm run test:determinism` completed twenty full three-lap races twice in Node for each math mode. Hashes matched within each mode; the slowest measured race was 342 ms with native math and 364 ms with explicit math. This does not prove equality across JavaScript engines or between the two math modes.

Two desktop browser screens in the isolated loopback lab completed a race with **307 matching checkpoints and no checkpoint mismatch**, including an injected 300 ms delivery delay on one screen. The inspected screens recorded 1,378 and 1,257 stalls, with largest measured catch-up batches of 3 and 5 ms. Their final visible ticks differed, so their final hashes are not a same-tick comparison. This is diagnostic smoke-test evidence; it does not justify switching production to peer lockstep. Online play now uses the server-owned runtime. The lab remains separate from production room authority.
