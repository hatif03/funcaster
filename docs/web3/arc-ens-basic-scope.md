# Arc and ENS product scope

Documentation edition: **6 November 2026**.

The supported blockchain integrations are Arc testnet payments and Sepolia ENS names. PostgreSQL holds durable application records and recovery state; local development uses files and explicit simulations. Main contains the game console, XP phone pads and integration code.

Implemented: game stakes, winner predictions, equal-seat cheers, creator publishing/passes/splits/claims, phone-bound names, scoped host authority, replay records and a sanitized receipt ledger. Arc ConditionalPot scripted public acceptance is complete. Public creator registration/pass and two predictions are confirmed; the stopped predictions were refunded. A successful full hosted game/cheer/payout round and creator claim remain open.

Keep amounts conserved, typed signatures bound to exact terms, seated players excluded from their own predictions, refunds available after deadlines, and honest proof labels. MOCK means simulation and cannot be described as a public transaction.
